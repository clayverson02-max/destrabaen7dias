# Destrabaen7dias

Este projeto deve publicar UMA página HTML estática que já está pronta. NÃO recrie, NÃO redesenhe e NÃO converta para React: use o arquivo exatamente como está, byte a byte.

Fonte do arquivo (é o mesmo conteúdo nos dois links):
https://raw.githubusercontent.com/clayverson02-max/quizclayverson/midia-instagram/ofertas/destrava/site/index.html
https://cdn.jsdelivr.net/gh/clayverson02-max/quizclayverson@20d4995d7c7241639990077f2dd05f0e9d96bdb9/ofertas/destrava/site/index.html

O que fazer:
1. Baixe esse arquivo e substitua o conteúdo inteiro do index.html da raiz do projeto por ele (o documento completo, com o <head> que tem o Meta Pixel 2149847235657959, o script da UTMify em cdn.utmify.com.br e o Microsoft Clarity z5kq0chvuf, e todo o <body> com o quiz, os estilos e o script).
2. O index.html final NÃO deve carregar /src/main.tsx nem montar o app React (remova essa tag de script). A página roda sozinha com o próprio JavaScript inline.
3. Mantenha todas as imagens e o vídeo apontando para os links cdn.jsdelivr.net que já estão no arquivo.
4. Não adicione nenhum outro elemento, cabeçalho, rodapé, fonte ou estilo.
5. Confira no preview: a página abre com o título "¿Tu cuerpo está trabado?", o botão "Empezar el test →" avança para as perguntas, e no final aparece a oferta com o cupom PRIMEROS50 e o botão que leva para https://pay.cakto.com.br/zyh5x7o_1260521.
